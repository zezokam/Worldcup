# كأس العالم 2026 — عرض شبكي مباشر 🏆

موقع خفيف وسريع يعرض منتخبات كأس العالم 2026 بعرض شبكي جميل ومتجاوب مع الجوال،
مع **نتائج مباشرة تتحدّث تلقائيًا بعد كل مباراة**.

- **المجموعات** — 12 مجموعة بجدول ترتيب مباشر (لعب، فارق الأهداف، النقاط) مع تمييز المتأهلين.
- **الأدوار الإقصائية** — شجرة مباريات من دور الـ32 حتى النهائي مع النتائج والبطل.
- **شريط المباريات المباشرة** أعلى الصفحة مع الدقيقة الحالية.
- تصميم عربي (RTL) داكن فاخر، يعمل بسلاسة على الجوال، تحديث تلقائي كل 60 ثانية وعند فتح الصفحة.

## المعمارية

```
المتصفّح ──▶ Cloudflare Worker ──▶ TheSportsDB (بدون مفتاح)
             │  • يخدم الصفحة (public/)
             │  • /api/bracket ينسّق البيانات ويخزّنها مؤقتًا على الحافة (60 ثانية)
             │  • Cron كل 5 دقائق لتسخين الكاش
```

جلب البيانات يتم على حافة Cloudflare (شبكة مفتوحة)، لذا التحديث الحيّ يعمل في الإنتاج.

- `src/worker.js` — منطق الجلب والتنسيق والتخزين المؤقت (stale-while-revalidate).
- `src/countries.js` — أسماء المنتخبات بالعربية + أعلام تُولَّد من رمز ISO.
- `public/` — الواجهة (HTML/CSS/JS بدون أي اعتماديات خارجية).

## النشر على Cloudflare

```bash
npm install
npx wrangler login            # أو صدّر CLOUDFLARE_API_TOKEN
npx wrangler deploy
```

### ربط الدومين worldcup.alkamali.uk

بعد أول نشر، اربط النطاق المخصّص بإحدى طريقتين:

**من لوحة التحكم:** Workers & Pages → `worldcup` → Settings → Domains & Routes →
Add Custom Domain → `worldcup.alkamali.uk` (يُضاف سجل DNS تلقائيًا لأن النطاق داخل Cloudflare).

**أو أضف إلى `wrangler.toml`** ثم أعد النشر:

```toml
[[routes]]
pattern = "worldcup.alkamali.uk"
custom_domain = true
```

## التطوير محليًا

```bash
npx wrangler dev      # http://localhost:8787
```
